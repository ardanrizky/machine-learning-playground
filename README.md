# Machine Learning Playground

A personal repository dedicated to hands-on Machine Learning experiments, end-to-end data projects, and interactive applications.

---

## Projects

### 1. [House Price Prediction](./house-price-prediction/)
- **Description:** Predicting median house values using the California Housing dataset.
- **Algorithm:** XGBoost Regressor
- **Key Techniques:** Exploratory Data Analysis, Correlation Heatmap, Feature Importance, R² & MAE Evaluation.
- **Components:**
  - Jupyter Notebook: [`house-price-prediction/california_housing_prediction.ipynb`](./house-price-prediction/california_housing_prediction.ipynb)
  - Streamlit Web App: [`house-price-prediction/app.py`](./house-price-prediction/app.py)
  - Public Dataset: [California Housing Prices (Kaggle)](https://www.kaggle.com/datasets/camnugent/california-housing-prices)

### 2. [Loan Approval Prediction](./loan-approval-prediction/)
- **Description:** Predicting bank loan eligibility using customer financial and demographic data.
- **Algorithm:** Support Vector Machine (SVM)
- **Key Techniques:** Data Cleaning, Categorical Encoding, Binary Classification, Train-Test Evaluation.
- **Components:**
  - Jupyter Notebook: [`loan-approval-prediction/loan_approval_prediction.ipynb`](./loan-approval-prediction/loan_approval_prediction.ipynb)
  - Streamlit Web App: [`loan-approval-prediction/app.py`](./loan-approval-prediction/app.py)
  - Public Dataset: [Loan Prediction Dataset (Kaggle)](https://www.kaggle.com/datasets/altruistdeloitte/loan-prediction-problem-dataset)
